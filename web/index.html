JAGA PERAIRAN
Deteksi dini ledakan alga berbahaya (HAB) — demo sisi-klien
Demo ini membangkitkan citra mikroskop sintetis lalu mendeteksi partikel di browser dengan thresholding + connected-components, mengklasifikasi berdasarkan ukuran. Detektor produksi (model terlatih untuk spesies) berjalan di layanan Python repo ini — bukan di halaman ini.
Data sintetis · klasifikasi berbasis ukuran untuk demonstrasi · produksi memakai model spesies terlatih.
